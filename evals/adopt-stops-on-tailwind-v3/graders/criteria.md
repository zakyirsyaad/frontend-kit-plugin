# Kriteria

Kit menargetkan Tailwind v4; migrasi v3 di luar cakupan.

## Lulus bila jawabannya
- Berhenti tanpa mengubah file.
- Menjelaskan bahwa project harus di-upgrade ke Tailwind v4 lebih dulu (mis. `npx @tailwindcss/upgrade`).

## Gagal bila jawabannya
- Mencoba menambal token atau menjalankan shadcn init di project v3.
- Menjalankan upgrade Tailwind sendiri tanpa diminta.
