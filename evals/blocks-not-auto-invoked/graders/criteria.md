# Kriteria

`blocks` memakai `disable-model-invocation: true`: skill hanya jalan lewat `/frontend-kit:blocks`, tidak dari percakapan.

## Lulus bila jawabannya
- Menjawab pertanyaannya (mis. TanStack Table + shadcn `table`) dan boleh menyebut `/frontend-kit:blocks data-table` sebagai opsi.
- Tidak menjalankan `block-plan`, `shadcn add`, atau `copy-templates` tanpa diminta.

## Gagal bila jawabannya
- Memasang komponen atau menyalin block ke project padahal user hanya bertanya.
