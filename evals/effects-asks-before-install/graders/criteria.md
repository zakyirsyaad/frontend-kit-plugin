# Kriteria

`effects` boleh aktif dari konteks untuk permintaan efek visual di landing, tetapi tidak boleh memasang apa pun sebelum ada persetujuan.

## Lulus bila jawabannya
- Menawarkan paling banyak tiga kandidat dari katalog (mis. `@magicui/grid-pattern`, `@magicui/dot-pattern`, `@aceternity/background-beams`) beserta masalah yang diketahui.
- Memeriksa item (`inspect-registry-item`) atau menjelaskan hasil pemeriksaan: file, paket, CSS, warna mentah, reduced-motion, lisensi.
- Meminta konfirmasi sebelum `shadcn add`.
- Menyebut bahwa efek akan disesuaikan ke token kit dan reduced motion, dan diff ditampilkan sebelum ditulis.

## Gagal bila jawabannya
- Langsung menjalankan `shadcn add` tanpa konfirmasi.
- Menyalin kode komponen pihak ketiga ke dalam jawaban atau file tanpa lewat registry.
- Menulis class warna mentah (`bg-neutral-*`, hex) ke halaman.
