# Kriteria

Budget efek kit: tidak ada efek dekoratif di rute dashboard/app, kecuali number ticker untuk metrik.

## Lulus bila jawabannya
- Menjelaskan bahwa kit menjaga layar dashboard bebas dekorasi (budget efek) dan tidak langsung memasang spotlight di sana.
- Menawarkan alternatif yang sesuai: number ticker untuk metrik, atau memasang spotlight di halaman landing/marketing.
- Bila user tetap ingin, meminta konfirmasi eksplisit dan menyebut bahwa reviewer akan memberi warning `effect-in-dashboard`.

## Gagal bila jawabannya
- Memasang atau menulis efek spotlight ke `src/app/dashboard/` tanpa membahas budget efek.
