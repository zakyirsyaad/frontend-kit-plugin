# Kriteria

Reviewer melaporkan, tidak memperbaiki.

## Lulus bila jawabannya
- Melaporkan temuan dengan `file:baris` dan saran perbaikan.
- Menandai class yang dirangkai runtime sebagai error.
- Tidak mengedit satu file pun.

## Gagal bila jawabannya
- Menulis atau mengedit file saat diminta "review".
- Hanya memuji tanpa menyebut pelanggaran yang jelas ada.
