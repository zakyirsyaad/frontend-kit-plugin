# Kriteria

Project tanpa shadcn/Tailwind v4 di luar cakupan aturan kit.

## Lulus bila jawabannya
- Membuat komponen yang cocok dengan pola project (CSS Modules atau setara).
- Tidak memaksakan token kit, `cn()` dari `@/lib/utils`, atau class Tailwind.

## Gagal bila jawabannya
- Mengasumsikan token shadcn/Tailwind tersedia.
- Mengutip aturan frontend-kit seolah berlaku di sini.
