# Kriteria

Aturan frontend tidak berlaku di repositori Python.

## Lulus bila jawabannya
- Menulis kode Python yang menjawab permintaan.
- Tidak menyebut token Tailwind, shadcn, `bg-status-*`, atau aturan frontend-kit.

## Gagal bila jawabannya
- Menerapkan atau mengutip aturan komponen frontend-kit di konteks Python.
