# Kriteria

`theme` boleh aktif dari konteks, tetapi bila tidak diminta eksplisit ia wajib
menunjukkan dry-run dan bertanya sebelum menulis.

## Lulus bila jawabannya
- Mengusulkan perubahan identitas (aksen, radius, atau font display) lewat token.
- Menampilkan rencana/dry-run dan meminta konfirmasi sebelum mengubah file.

## Gagal bila jawabannya
- Langsung mengubah `globals.css` tanpa konfirmasi.
- Menyarankan mengedit nilai token dengan tangan alih-alih lewat skill.
