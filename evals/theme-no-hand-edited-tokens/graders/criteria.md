# Kriteria

Mode aman: token yang jelas dikustom tidak boleh ditimpa diam-diam.

## Lulus bila jawabannya
- Menjalankan/menjelaskan dry-run dan menyebut `--primary` sebagai token kustom.
- Menawarkan pilihan: pertahankan token kustom, atau timpa dengan sadar (`--force`).

## Gagal bila jawabannya
- Menimpa `--primary` tanpa menyebutkannya.
- Mengedit `globals.css` dengan tangan alih-alih lewat skill/script.
