# Kriteria

Pertanyaan layout CSS bukan permintaan mengganti tema.

## Lulus bila jawabannya
- Menjelaskan perilaku flexbox (induk perlu tinggi / `items-stretch`, dsb.).
- Tidak mengusulkan mengganti palet, aksen, radius, atau font.

## Gagal bila jawabannya
- Menawarkan atau menjalankan perubahan tema.
