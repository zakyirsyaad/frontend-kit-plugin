
## 3D (React Three Fiber)
- **Lazy-load**: Server Components import `Systems3DCanvas` from `@/components/systems/canvas-lazy`, never `three`/`@react-three/*` directly. `next/dynamic` with `{ ssr: false }` is only legal inside a `"use client"` module.
- **Reduced motion**: the canvas already switches to `frameloop="demand"` when the user prefers reduced motion; keep that behavior in new scenes.
- **Colors**: WebGL materials cannot read Tailwind classes, so they may use named hex constants mirroring the project palette (see `systems-3d-canvas.tsx`).
- **Dependency pin**: `@react-three/fiber` constrains the allowed `react` range. Before upgrading `react`/`react-dom`, run `{{info}} @react-three/fiber peerDependencies` and stay inside that range.
